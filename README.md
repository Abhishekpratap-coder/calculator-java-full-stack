# A simple Smart Menu Calculator built using Java and Scanner.
This project is a console-based calculator that allows users to perform different mathematical operations through a menu.
🛠️ Technologies Used
Java
Scanner Class
Math.pow()
Switch Case
Do-While Loop
Object-Oriented Programming (OOP)

🚀 How to Run
1. Clone the Repository
git clone https://github.com/Abhishekpratap-coder/calculator-java-full-stack.git

2. Open the Project
Open the project in any Java IDE such as:
IntelliJ IDEA
Eclipse
VS Code
NetBeans
3. Compile the Program
javac MenuCalculator.java

4. Run the Program
java MenuCalculator
